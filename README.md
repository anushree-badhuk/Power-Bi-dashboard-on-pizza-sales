# 🍕 Pizza Sales Power BI Dashboard

An interactive Business Intelligence dashboard built using Power BI to analyze pizza sales performance, revenue trends, customer purchasing habits, and top-selling menu items.

---

## 📊 Project Overview
This project visualizes comprehensive sales data to help restaurant stakeholders understand business performance and optimize operations. The dashboard provides clear insights into:
* **Peak Ordering Times:** Identifying the days and hours with the highest order volume.
* **Revenue Drivers:** Determining which pizza categories and sizes generate the most income.
* **Menu Performance:** Highlighting the best and worst-selling items to inform inventory and marketing strategies.

---

## 🛠️ Tools & Technologies Used
* **Power BI:** Data modeling, writing DAX measures, and designing interactive report layouts.
* **Power Query / ETL:** Data cleaning, transformation, and shaping raw sales data.
* **Dataset:** Transactional records covering order details, pricing, quantities, categories, and timestamps.

---

## 📈 Key Dashboard Features & Insights
* **Sales Summary Cards:** Displays total revenue, total orders, total pizzas sold, average order value, and average pizzas per order.
* **Trend Analysis:** Visualizes hourly and daily trends to identify peak business hours.
* **Category & Size Distribution:** Breaks down sales proportions across different pizza categories (e.g., Classic, Chicken, Supreme, Veggie) and sizes.
* **Top/Bottom Performers:** Ranks the top 5 best-selling pizzas and bottom 5 underperforming items by revenue and total quantity.
